# Sysadmin Pro

A Sololearn-style Android app for advanced IT: PowerShell scripting, subnetting,
VLANs and DNS, Group Policy and AD internals, servers and backups, Entra ID /
Intune / Exchange Online, and Linux for Windows admins.

Lessons live in `app/src/main/assets/index.html`; `MainActivity.java` shows that page.
The "Build APK" GitHub workflow builds the APK on every push.
