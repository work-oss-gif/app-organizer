# Help Desk Academy

A Sololearn-style Android app for learning everyday IT: Windows, networking,
Active Directory, PowerShell, Microsoft 365 and troubleshooting.

The lessons live in `app/src/main/assets/index.html`. The app is one screen
(`MainActivity.java`) that shows that page.

## Get the APK
Push this folder to GitHub. The "Build APK" workflow runs automatically.
Open the Actions tab → the latest run → Artifacts → download
`HelpDeskAcademy-apk`, unzip it and install `app-debug.apk` on your phone.
